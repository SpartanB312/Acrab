## Acceptance

Stack evidence must identify the actual values consumed by consecutive branches,
including locals, duplication, wide values, merges and exception handlers.
Numeric facts retain JVM semantics and unknown/conflicting values. Contextual
results record assumptions rather than promote them to whole-program facts.

Evidence must bind to current source bytes and fail when stored bytes change.
References preserve descriptors and raw ASM indexes. String recovery is limited
to supported static transforms with derivation evidence; it never invokes target
methods. Structure comparison accounts for explicit naming maps.

The client must handle initialization notifications, independent sessions,
UTF-8 argument files, full responses and actionable failures. Evidence exports
must preserve requests and responses and detect altered records.

The source case ZIP must rebuild after clean extraction and include its build
instructions. An intentionally incorrect trim implementation must fail an
independent behavioral test. Runtime testing uses an explicit external harness,
never a target execution capability in the MCP server.

The root skill is the main-agent entrypoint. Every specialist has a documented
intelligence requirement and escalation triggers. Routing uses the host's actual
supported models and respects user choices and single-agent constraints.

Final checks: full Gradle build, fixture MCP regression, helper-script validation,
skill validation, clean ZIP/TAR extraction and launch/resource checks, and clean
Git status after milestone commits.
